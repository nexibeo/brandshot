# Profile text: limits and patterns

Character limits (checked 2026-09-19). Count with code; emoji can count as 2 on some platforms, so leave a few characters spare.

| Platform | Field | Limit |
| --- | --- | --- |
| YouTube | Channel description | 1,000 |
| YouTube | Channel name / handle | 50 / 30 |
| Instagram | Bio | 150 |
| Instagram | Name | 30 |
| Threads | Bio | 150 (edited on Threads itself; it does not always mirror Instagram) |
| LinkedIn (personal) | Headline / About | 220 / 2,600 |
| LinkedIn (company) | Tagline / About | 120 / 2,000 (secondary sources) |
| X | Bio / display name | 160 / 50 |
| Facebook | Page bio | 101 |
| TikTok | Bio | 80 |
| Bluesky | Bio / display name | 256 / 64 |
| Pinterest | About | 500 |

## Patterns that work

- **Short bios (Instagram, TikTok, X, Facebook):** line 1 says what you do for whom, with an emoji at the start if it suits the brand. Line 2 is proof or the key detail. Line 3 is the offer or call to action. The link goes in the link field, not the bio.
- **Long descriptions (YouTube, LinkedIn About, Pinterest):** the first sentence repeats the promise and must work on its own, because it is often truncated. Then what the audience gets, how often, and who it's for. End with the links (site, contact).
- **LinkedIn headline:** role or offer plus a clear outcome, not a list of buzzwords.
- Don't claim anything the brand's site doesn't say.

Put the character count next to every field.
